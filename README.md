# Revit Addin Installation

Before unzip the .rar file

Open the proporties and check the box below

<img width="400" height="544" alt="image" src="https://github.com/user-attachments/assets/2622c7d9-4590-44c9-b105-5ce44c129443" />

<img width="450" height="509" alt="image" src="https://github.com/user-attachments/assets/d3a7f23c-90b4-45ae-8f60-1c199167f034" />

Double click "Multi_Revit_Version_Install.bat"

<img width="590" height="176" alt="image" src="https://github.com/user-attachments/assets/878bdf0c-6e76-47f2-8ccc-0cdb549453dc" />

Enter the revit version (2022 to 2025) in cmd.exe and press Enter

<img width="232" height="58" alt="image" src="https://github.com/user-attachments/assets/7ee98da9-0e02-4f9b-b015-f4fe780a0d2a" />

Press enter when "Press any key to continue..." show up.

<img width="1089" height="544" alt="image" src="https://github.com/user-attachments/assets/22fc68dc-29ff-4c2d-b8b1-5ea6fdbce1f9" />

A filepath "C:\ProgramData\Autodesk\Revit\Addins\2022" will automatic open.

Check if "Multi_Revit_Version" and "Multi_Revit_Version_2022.addin" exsit in the folder.

<img width="1312" height="764" alt="image" src="https://github.com/user-attachments/assets/55c7b251-c49a-4e1f-8d4c-661abd024392" />

Start corresponding revit version and click "Load Once" or "Always Load"

"Load Once" for load the addin this time ONLY.

"Always Load" will automatic load the addin everytime.

<img width="679" height="321" alt="image" src="https://github.com/user-attachments/assets/d81d41ba-58a8-46fd-a977-e3cd690636e2" />

A new ribbon name "Addin_2022" will be create

<img width="1327" height="137" alt="image" src="https://github.com/user-attachments/assets/e05ac792-ee82-4388-b884-cde674d76b2a" />


Installation done.

Contact Tobias if there any problem.
